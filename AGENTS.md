# Working on Engineering Relay

Preserve the engineering reference guides in `docs/`. Shared procedures live in `skills/`, artifact contracts in `schemas/`, and runner behavior in `lib/`. Native agent entry points are generated by `node scripts/sync-adapters.mjs`; edit canonical skills rather than their wrappers.

For runner, contract, or packaging changes, run `npm test` and `npm run check`. Run `npm run example` to verify the full feature workflow. Tests should establish observable evidence and state invariants, not just generated wording. Keep public commands and artifact examples consistent with their schemas.
